## 背景

前几轮全部集中在解析引擎与服务层，工具链、后台 UI 与部署形态仍停留在上游 2026-04 的状态：
Gradle 8.10 已被 Kotlin 标记为即将不支持，后台还在用 2012 年的 jQuery UI 1.8.22 与 layui 2.9.18，
运行镜像是非 LTS 的 JDK 22，生产配置里还留着明文管理员密码与三个未被引用的旧配置文件。
本轮把这些一并收口，并把「什么算做完」写进 README。

## 变更

### 引擎（book/）

本轮无新增引擎改动（`getElements` / `getObject` 容错已在上一批发布中）。

### 服务层（src/main/kotlin、templates）

- `templates/login.html`、`templates/regester.html` 移除 `jquery-ui.min.js` 引用，
  并删除 `static/static/js/jquery-ui.min.js`（1.8.22，2012 年）。
  依据：全仓库检索确认**没有任何 jQuery UI API 调用**，两页只用 `layui.jquery`；
  且 layui 不暴露 `window.jQuery`，升级到 1.14 反而会 `ReferenceError`，故直接移除死依赖。

## 风险与注意事项

1. **管理员密码已更换**：迁移到 bcrypt 时工具要求 ≥12 位，因此密码必须换新。
   旧密码立即失效；新密码由本次操作生成并单独交付，不要写进仓库。
2. **Gradle 8.14 的 TLS 问题**：新 HTTP 客户端在双栈网络下会优先 IPv6，
   若 IPv6 到 Maven Central 不通，会报 `Remote host terminated the handshake`。
   已在 `gradle.properties` 用 `systemProp.java.net.preferIPv4Stack=true` 兜底。
3. **容器镜像更换**：`docker-compose.yml` 的 `image` 已改为 `eclipse-temurin:21-jre`。
   1Panel 的 App 页面如果重新下发 compose 配置，可能把镜像改回 `1panel/java:*`，
   届时需再次修改或把 `JAVA_VERSION` 对应镜像替换掉。
4. **后台 UI 升级只做了 HTTP 级验证**：5 个页面均 200、静态资源均可达、登录链路正常；
   没有做像素级视觉回归，若发现样式异常可回滚 `static/static/layui/` 与两个模板。
